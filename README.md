## Learning Approach

I don't want this repository to be a collection of copied tutorial code.

My approach is:

1. Learn a concept.
2. Implement it myself.
3. Build something practical with it.
4. Identify mistakes and improve the implementation.
5. Keep the projects that add value to my learning journey.
